Install

" Vim 8 packages (both colors/ and autoload/ are required):
git clone https://github.com/Real-Fruit-Snacks/terminal-workbench-vim ~/.vim/pack/themes/start/twb.vim

" vimrc:
set termguicolors
colorscheme twb-dark        " or twb-light

Without termguicolors the themes fall back to hand-tuned xterm-256 colors automatically. Requires Vim 8+; loads in Neovim too. No italics anywhere; Vim's :terminal gets a matching ANSI palette.
